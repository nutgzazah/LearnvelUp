# LearnvelUp 🦦📱

**LearnvelUp** is a mobile learning application built with **React Native (Expo)**. It focuses on providing a seamless learning experience with a modern, responsive UI powered by NativeWind and efficient data handling via TanStack Query.

## ✨ Key Features

- **Authentication:** Secure Login & Register flow with Supabase Auth.
- **Navigation:** File-based routing using **Expo Router**.
- **Data Management:**
  - **Server State:** Efficient data fetching, caching, and synchronization with **TanStack Query**.
  - **Client State:** Global user session management with **Zustand**.
- **Styling:** Utility-first styling with **NativeWind v4** (Tailwind CSS for React Native).
- **Custom UI:** Custom fonts (K2D) and themed components.

## 🛠 Tech Stack

- **Core:** [React Native](https://reactnative.dev/) / [Expo SDK](https://expo.dev/)
- **Navigation:** [Expo Router](https://docs.expo.dev/router/introduction/)
- **Data Fetching:** [TanStack Query](https://tanstack.com/query/latest) (React Query)
- **State Management:** [Zustand](https://github.com/pmndrs/zustand)
- **Styling:** [NativeWind v4](https://www.nativewind.dev/)
- **Backend & Auth:** [Supabase](https://supabase.com/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
